# Veyra Scope visual direction

Veyra Scope is a rack-mounted signal bench for inspecting LiDAR truth. The
interface uses a charcoal instrument surface, bone-white silkscreen labels,
steel hairlines, and red/amber/green LEDs only when they carry operational
meaning. Square controls and compact tabular readouts keep the visual language
close to the data's physical origin.

The primary hierarchy is: point-cloud scope, current frame identity, then
provenance and class distribution. The viewer must never fill a missing frame,
label, pose, or measurement with fabricated data. Loading, empty, pairing,
and error states are explicit. Motion is limited to loading continuity and the
active frame sweep, with a reduced-motion path.

Typography is the existing system sans for interface copy and system
monospace for frame IDs, counts, timestamps, and status. The radius system is
square by default; no decorative gradients, blobs, or generic dashboard
metrics are part of the surface.
